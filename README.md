# relay board with NO/NC dry switch, that managed by mqtt message from HomeAsisstant 'switch' object
Alhough there are many great solutions based on ESP32 controller, my goal is to build it on RTL8720CF (AmebaZ2/ZII Series) board.


# Used modules

* BW15 board.
* 5V -> 3.3V linear voltage regulator
* USB -> TTL adapter for flashing

# Some features

* Auto-discovery is used for automatic configuration of switch object in HomeAssistant
